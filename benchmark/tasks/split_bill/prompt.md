Write a function called `split_bill` that splits a restaurant bill evenly between a number of people. It takes the
total as text, like "100.00", and the number of people, and gives back each person's share as text with two decimals,
like "33.34". The shares must add up exactly to the total; when it doesn't divide evenly, the first people pay the
extra cent. A negative or invalid total, or fewer than one person, should cause an error.
